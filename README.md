VKclips
================================================================================

Бот собирает YouTube Shorts по хэштегам, уникализирует через FFmpeg
и постит в сообщества VK по расписанию.

--------------------------------------------------------------------------------
ЧТО УМЕЕТ
--------------------------------------------------------------------------------

- Собирает Shorts по тегам из hash.txt и фильтрует по просмотрам,
  лайкам, длительности.
- Уникализирует видео через FFmpeg (кроп, скорость, цвет, вотермарка,
  метаданные).
- Постит в VK с лимитами на группу и аккаунт, кулдауном
  и паузой между публикациями.
- Использует заданный постоянный VK-токен без автообновления.
- Чистит старые посты и собирает статистику раз в сутки.
- Шлёт алерты в VK админу.

--------------------------------------------------------------------------------
ТРЕБОВАНИЯ
--------------------------------------------------------------------------------

- Python 3.10+
- FFmpeg (в PATH)
- Постоянный пользовательский VK-токен с правами на публикацию
- YouTube Data API v3 ключ

--------------------------------------------------------------------------------
УСТАНОВКА
--------------------------------------------------------------------------------

    git clone <URL>
    cd VKclips2

    python -m venv .venv
    .venv\Scripts\activate          # Windows
    source .venv/bin/activate       # Linux/macOS

    pip install -r requirements.txt

--------------------------------------------------------------------------------
НАСТРОЙКА
--------------------------------------------------------------------------------

1. Скопируй .env.example в .env и заполни:

    VK_ACCESS_TOKEN=
    VK_GROUP_TOKEN=
    VK_GROUP_ID=
    VK_ADMIN_ID=
    YT_API_KEY=

   `VK_ACCESS_TOKEN` — постоянный пользовательский токен для публикации,
   очистки и статистики. `VK_GROUP_TOKEN` — отдельный токен сообщества
   для LongPoll и сообщений. `VK_GROUP_ID` указывай положительным числом.
   `VK_ADMIN_ID` также служит получателем уведомлений. Если нужен другой
   получатель, можно дополнительно задать `VK_ALERT_PEER_ID`.
   Токены проект не обновляет; менять их нужно только в .env.

2. Хэштеги — в hash.txt, по одному на строку, без #.

3. Настройки (лимиты, интервалы, фильтры) — в config/config.py.

4. Добавь сообщество через add_group.py (ID берётся из VK_GROUP_ID,
   дневной лимит — из DAILY_LIMIT_DEFAULT в config/config.py):

    python add_group.py

   Для уже добавленной группы лимит хранится в БД: изменение
   DAILY_LIMIT_DEFAULT меняет только лимит новых групп.

5. Опционально: watermark.mov для вотермарки.

--------------------------------------------------------------------------------
ЗАПУСК
--------------------------------------------------------------------------------

После настройки .env:

    python run_all.py

Остановка — Ctrl+C.

--------------------------------------------------------------------------------
СТРУКТУРА
--------------------------------------------------------------------------------

    VKclips2/
    |-- run_all.py              # оркестратор
    |-- add_group.py            # добавление группы
    |-- patch.py                # патчер настроек
    |-- hash.txt                # хэштеги
    |-- config/config.py        # все константы
    |-- core/                   # логика (db, youtube, processor,
    |                           # notifier, ...)
    |-- scripts/                # populator, loader, vk_listener,
    |                           # vk_cleaner, stats_collector
    |-- data/                   # БД и служебные файлы (не коммитить)

--------------------------------------------------------------------------------
КАК РАБОТАЕТ
--------------------------------------------------------------------------------

1. populator — собирает ID Shorts с YouTube, фильтрует, кладёт в очередь.

2. loader — берёт из очереди, скачивает, уникализирует, постит в VK.

3. vk_listener — слушает события VK.

4. vk_cleaner + stats_collector — раз в сутки чистят и собирают
   статистику.

5. run_all.py — следит за процессами и перезапускает упавшие.

--------------------------------------------------------------------------------
ЛОГИ

--------------------------------------------------------------------------------
ЧАСТЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------

"Не удалось подготовить VK-токен"
    -> укажи VK_ACCESS_TOKEN в .env или окружении и перезапусти run_all.py.

FFmpeg не найден
    -> установи и добавь bin в PATH, либо поправь FFMPEG_PATH
       в core/processor.py.

Все видео отфильтровываются
    -> ослабь MIN_VIEWS, MIN_LIKES_RATIO в config/config.py.

Посты не уходят
    -> проверь daily_limit группы и лимит аккаунта
       в core/account_guard.py.
